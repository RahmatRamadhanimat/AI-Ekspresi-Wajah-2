Arsitektur & Teknologi

Tentang Aplikasi & Model AI

Aplikasi deteksi ekspresi wajah ini memadukan kemudahan Google Teachable Machine dengan kecanggihan TensorFlow.js untuk menghadirkan inferensi machine learning langsung di browser.

Google Teachable Machine

Platform web berbasis transfer learning dari MobileNet yang memungkinkan siapa saja melatih model machine learning klasifikasi gambar tanpa perlu menulis kode matematika yang rumit.

TensorFlow.js Engine

Library open-source untuk menjalankan model neural network di browser menggunakan JavaScript dan akselerasi WebGL, memberikan performa deteksi real-time bebas latency jaringan.

Panduan Model Kustom

Ingin menggunakan model Anda sendiri? Latih 3 kelas (Senang, Sedih, Netral) di Teachable Machine, klik Export -> Upload, lalu masukkan link shareable Anda ke aplikasi ini.

Langkah Melatih Model Sendiri di Google Teachable Machine

1

Buka Teachable Machine

Kunjungi teachablemachine.withgoogle.com dan pilih Image Project -> Standard Image Model.

2

Buat 3 Kelas Ekspresi

Beri nama kelas: Senang (atau Happy), Sedih (atau Sad), dan Netral (atau Neutral). Rekam sampel wajah menggunakan webcam untuk setiap kelas (masing-masing 80-150 gambar).

3

Latih Model (Train)

Klik tombol Train Model dan tunggu hingga proses pelatihan selesai di browser Anda tanpa menutup tab.

4

Export & Salin Link Model

Klik Export Model, pilih tab TensorFlow.js, pilih opsi Upload (shareable link), lalu salin URL yang dihasilkan (misal: https://teachablemachine.withgoogle.com/models/xyz123/).

5

Gunakan di Website Ini

Klik tombol Pengaturan Model di pojok kanan atas website ini, tempelkan URL Anda, lalu klik Terapkan Model. Selesai!
